# Clegra releases

Clegra is an AI assistant for people and companies: one chat that works with your mail, calendar, documents and business apps, on the web and on the Mac.

**Download:** [clegra.com/download](https://clegra.com/download)

This repository only hosts the published builds of the Clegra desktop app. Each [release](https://github.com/andreazagoit/clegra-releases/releases) holds the signed and notarized Mac app (`.dmg` to install, `.zip` for updates) and its release notes.

## Updates

The Mac app checks this repository's latest release when it starts, when the Mac wakes and from **Clegra → Check for Updates…**. A newer version downloads in the background, is verified (checksum and Apple Developer ID signature) and installs when you restart the app.

The latest installer is always at
`https://github.com/andreazagoit/clegra-releases/releases/latest/download/Clegra-arm64.dmg` (Apple Silicon, macOS 13 or later).
